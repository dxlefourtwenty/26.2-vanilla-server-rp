Minecraft 26.2 compatibility fixes for this server's pack set.

Mobs Drop Eggs, and Recipes+.

It combines the Mobs Drop Eggs and Ancient Artifacts ghast/phantom loot tables,
updates the Recipes+ horse predicate, and updates Enchantment Plus entity-type
predicates to the Minecraft 26.2 schema.
