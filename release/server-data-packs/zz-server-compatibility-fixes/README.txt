Minecraft 26.2 compatibility fixes for this server's pack set.

This pack must have higher priority than Ancient Artifacts, Enchantment Plus,
Mobs Drop Eggs, and Recipes+.

It combines the Mobs Drop Eggs and Ancient Artifacts ghast/phantom loot tables,
updates the Recipes+ horse predicate, and updates Enchantment Plus entity-type
predicates to the Minecraft 26.2 schema. It also lets Recipes+ own blast-furnace
recycling by filtering the three conflicting vanilla nugget recipes and moves
the vanilla purpur-pillar recipe horizontal so both slab recipes remain usable.
